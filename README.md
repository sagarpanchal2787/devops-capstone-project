# devops-capstone-project

## Customer Accounts Microservice

This project is a customer accounts microservice for an e-commerce application. The service provides REST APIs for managing customer account information, including customer names and addresses.

The project will implement APIs to read, update, delete, and list customer accounts. The microservice will be developed using Python Flask and will later be containerized with Docker and deployed to Kubernetes.

### Project Objectives

- Set up the development environment
- Implement REST APIs for reading customer accounts
- Implement REST APIs for updating customer accounts
- Implement REST APIs for deleting customer accounts
- Implement REST APIs for listing customer accounts
- Containerize the microservice using Docker
- Deploy the Docker image to Kubernetes
